# Mac App Store screenshots

No screenshots are generated or stored here because final captures must come from the exact Store
build and must contain only invented/demo data.

Mac screenshots accepted by App Store Connect are exactly one of these pixel sizes:

- 1280 × 800
- 1440 × 900
- 2560 × 1600
- 2880 × 1800

Confirm Apple's current requirements in App Store Connect at upload time. Use PNG or high-quality
JPEG without transparency, keep every screenshot in one supported size, and capture the app on
macOS without adding a device frame. Avoid unrelated desktop content, notifications, personal
names, recordings, transcripts, account details, or other private information.

Recommended truthful sequence: active recording panel; recent calls; completed transcript;
Models settings; Vocabulary; Recovery. Do not show speaker identification or speaker review: that
optional external-runtime feature is unavailable in the submitted Store version. Do not show
transcript search or MCP integration; neither is available in the Store version.
Show only UI and capabilities present in the submitted version. Preserve an untouched capture set
and document the build number, macOS version, display scaling, and demo-data seed used.
